# Terrarium

A pixel-art creature-keeping game, packaged as an installable web app.

## Play on your phone

1. Open the GitHub Pages URL: https://ryanhughes-rcd.github.io/terrarium/
2. **iPhone (Safari):** Share → *Add to Home Screen*.
   **Android (Chrome):** ⋮ menu → *Install app* / *Add to Home screen*.

It launches full-screen, works offline after the first load, and saves your progress on the device.
